Tongits TwoBots

Three-player Tongits — you against two bots. Offline.

Play it now · not on stores yet

Tongits is a Filipino card game: three players, a 52-card deck, melds and discards, and three ways a hand can end. The name is the pitch — the other two seats are bots, so a hand takes as long as you want it to and never waits on anyone.

Free. Install it from the browser and it plays with the network off — there is no server to be offline from.

  • doneThe engine: full hands, all three endings reachable, chips zero-sum across 10,000 simulated hands, no seat advantage.
  • donePlayable in a browser against two bots, and installable as an offline app.
  • doneA public URL, so the playtest can actually happen.
  • nextA real playtest — five players, one URL. That is the quality gate everything after it depends on.
  • thenAndroid, as a thin shell around the web build. Then iOS, only if it earns it.

karhu

An attribute-routed PHP 8.3+ microframework with zero runtime dependencies.

composer require bjornbasar/karhu

v0.1.4 · MIT · PHP 8.3+ · PHPStan level 8

Its own request/response layer, a reflection-based auto-wiring container, an onion middleware pipeline and a CLI — in roughly 1,200 lines. Architecture decisions are kept as ADRs in the repo, and it is built test-first.

Documentation ↗GitHub ↗Packagist ↗

The companion packages

Each small, focused, and independently composable.

  • karhu-db — a thin PDO wrapper with an active-record base. v0.1.0 · MIT composer require bjornbasar/karhu-db
  • karhu-queue — a database-backed queue and worker, using SKIP LOCKED. v0.3.0 · MIT composer require bjornbasar/karhu-queue
  • karhu-view — a template-engine bridge for Twig and Plates. v0.1.0 · MIT composer require bjornbasar/karhu-view

karhu-db ↗karhu-queue ↗karhu-view ↗

Where these actually are, stated plainly. Everything above is 0.x, and karhu-db and karhu-view last released in April 2026. They are stable in the sense that they run in production every day — not in the sense of a 1.0 promise or a release cadence.
